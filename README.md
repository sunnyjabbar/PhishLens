# PhishLens

A Python cybersecurity project that analyses emails for potential phishing warning signs.

## Features
- Detects suspicious links
- Checks sender email formats
- Identifies urgent or threatening language
- Flags potentially risky attachments
- Generates a risk score

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run `python phishlens.py` in the terminal.

## Technologies
- Python
- Regular Expressions
- URL Parsing

## Disclaimer
PhishLens identifies potential warning signs, not proof of phishing. A low risk score does not guarantee an email is safe.
